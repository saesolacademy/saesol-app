# 새솔학원 관리 앱

원장님과 선생님이 함께 쓰는 학원 관리 앱입니다.

## 지금 들어 있는 기능 (1단계: 학생 관리)

| 메뉴 | 하는 일 | 누가 |
|---|---|---|
| 대시보드 | 오늘 수업, 피드백 마감 D-day, 출결 알림, 이탈 신호를 한눈에 | 모두 |
| 출결 알림 | 출석·지각·결석·조퇴를 체크하면 학부모님께 문자 | 모두 |
| 피드백 작성 | 기간별 피드백 쓰기, 골라서 한 번에 보내기 | 모두 |
| 이탈 신호 관리 | 결석·지각이 잦은 학생 자동 표시 + 직접 표시 | 모두 |
| 피드백·문자 발송 기록 | 보낸 문자 전체 기록 | 원장은 전체, 강사는 본인 것 |
| 상담 정리 | 상담 내용과 해야 할 일 기록 | 모두 |
| 학생 명단 | 학생 정보 (원장만 등록·수정) | 원장은 전체, 강사는 자기 반 학생만 |
| 선생님 계정 · 반 관리 · 피드백 기간 · 설정 | 원장 전용 | 원장 |

## 원장 / 강사 구분

- **원장**: 모든 메뉴, 모든 학생
- **강사**: 원장 전용 메뉴가 보이지 않고, **자기가 맡은 반의 학생만** 볼 수 있습니다.
  화면에서만 숨긴 것이 아니라 서버에서도 막아 둡니다.

## 문자 발송

처음에는 **미리보기 모드**라서 문자가 실제로 나가지 않습니다. (발송 기록에만 남아요)
실제로 보내려면 Cloudflare 의 이 앱 설정 → 변수에 아래 세 가지를 "비밀(Secret)"로 넣고,
앱의 [설정]에서 "실제 발송"을 고르면 됩니다.

- `SOLAPI_API_KEY`
- `SOLAPI_API_SECRET`
- `SOLAPI_SENDER` (솔라피에 등록된 발신 번호, 숫자만)

## 나중에 학생 앱을 붙일 때

- 계정 표(users)에 `student` 역할과 `student_id`(학생 연결) 칸을 미리 만들어 두었습니다.
- 로그인(`/api/login`)은 쿠키뿐 아니라 `Authorization: Bearer 토큰` 방식도 받습니다.
  그래서 별도의 학생 앱(휴대폰 앱 포함)도 같은 서버·같은 데이터를 쓸 수 있습니다.
- 숙제 올리기 기능은 다음 단계에서 `homework` 표와 학생 전용 주소(`/api/student/...`)를 추가하면 됩니다.

## 파일 구성

```
wrangler.toml      Cloudflare 설정 (database_id 한 줄만 바꾸면 됨)
src/index.js       서버: 주소별 기능, 권한 확인
src/schema.js      데이터베이스 표 설계 (앱이 처음 켜질 때 자동으로 만들어짐)
src/auth.js        로그인, 비밀번호 암호화
src/sms.js         솔라피 문자 발송
public/            화면 (index.html, app.js, style.css)
```
